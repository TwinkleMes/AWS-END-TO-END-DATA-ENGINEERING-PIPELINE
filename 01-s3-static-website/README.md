# AWS S3 Static Website Hosting

## Project Overview

This project demonstrates how to host a static website using Amazon Simple Storage Service (Amazon S3). It covers creating an S3 bucket, enabling static website hosting, uploading an HTML homepage, configuring public read access, and verifying the website through the S3 website endpoint.

## Technologies Used

- Amazon Web Services (AWS)
- Amazon S3
- HTML and CSS
- S3 Bucket Policies and Permissions

## AWS Region

Asia Pacific (Mumbai) — `ap-south-1`

## Architecture

User's Browser → Amazon S3 Static Website Endpoint → `index.html`

## Implementation Steps

1. Created an S3 bucket named `twinkle-s3-static-hosting-2026`.
2. Enabled static website hosting and configured `index.html` as the index document.
3. Designed and uploaded the website files.
4. Configured the bucket policy to allow public read access to website objects.
5. Opened the S3 website endpoint to verify the hosted website.

## Website

[Open the hosted website](http://twinkle-s3-static-hosting-2026.s3-website.ap-south-1.amazonaws.com)

## Key Learnings

- Understanding Amazon S3 buckets and objects.
- Hosting static websites using AWS.
- Configuring bucket policies and public access.
- Testing a website using an S3 website endpoint.
