Project overview

Simple setup. Real cloud concepts.

The website is made of static files. Amazon S3 stores those files and serves the homepage through its website endpoint.

▤

Amazon S3 Bucket

A dedicated storage bucket holds the website's homepage and other static assets.

⌘

Static Website Hosting

The bucket is configured to use index.html as its default index document.

↗

Website Endpoint

Visitors can open the deployed page through the AWS Region-specific website endpoint.

Deployment workflow

From file to live website

These are the main steps completed in the AWS console.

STEP 01

Create bucket

Create a dedicated S3 bucket in the Mumbai Region.

STEP 02

Enable hosting

Enable static website hosting and set the index document.

STEP 03

Upload files

Upload the index.html homepage to the bucket.

STEP 04

Verify access

Open the website endpoint and confirm the page loads.
