# AWS End-to-End Data Engineering Projects

Welcome to my AWS Data Engineering portfolio! This repository documents hands-on projects that demonstrate my learning and practical implementation of cloud storage, event-driven automation, and ETL data pipelines using Amazon Web Services (AWS).

## About This Repository

The projects in this repository explore core AWS services and data engineering concepts, with project documentation and implementation details.

## Projects

### 1. AWS S3 Static Website Hosting

Hosted a static website using Amazon S3 and configured website hosting and public read access for the website files.

**Technologies:** Amazon S3, HTML, CSS

[View Project 1](./01-s3-static-website/)

### 2. AWS S3 Event-Driven Automation Using Lambda

Configured an Amazon S3 event trigger to invoke an AWS Lambda function when a file is uploaded. The function processes the event details and logs information about the uploaded file.

**Technologies:** Amazon S3, AWS Lambda, Python, Amazon CloudWatch

[View Project 2](./02-s3-event-driven-lambda/)

### 3. AWS Glue ETL Pipeline with Amazon S3

Built a visual ETL pipeline to discover employee CSV schema using an AWS Glue Crawler, remove the `city` column, and write transformed data to Amazon S3 in Parquet format.

**Technologies:** Amazon S3, AWS Glue, AWS Glue Data Catalog, Python/PySpark, CSV, Parquet

[View Project 3](./03-aws-glue-etl-pipeline/)

## Skills Demonstrated

- Cloud storage using Amazon S3
- Event-driven processing using AWS Lambda
- Data discovery and cataloging using AWS Glue
- ETL pipeline design and data transformation
- Structured data formats including CSV and Parquet
- Basic cloud resource configuration and troubleshooting

## AWS Region

Asia Pacific (Mumbai) — `ap-south-1`, where applicable to the documented projects.
